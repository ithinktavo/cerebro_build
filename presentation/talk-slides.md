# A work vault your AI tools can read

Obsidian, plus Claude Code, Codex, and Copilot, plus your tracker

---

## The problem

- Every AI session starts from zero
- Context is in heads, chats, documents, and the tracker
- Status reports get rebuilt from memory every week

---

## The idea

One folder of plain Markdown notes

- Your notebook, in Obsidian
- The AI's context, read first in every session
- One rulebook every tool follows: `AGENTS.md`

---

## What is in it

```
Home.md      what is current
Projects/    one hub per project
Teams/       one hub per team
Blueprints/  one hub per repository
Library/     reusable knowledge
Daily/       one note per day
System/AI/   the AI's memory and change log
```

---

## How a session goes

1. The tool reads Me, Home, the memory note, the hub
2. It does the work
3. It writes the log, updates the hub, and tells you what changed

---

## The tracker stays the system of record

- Jira, Azure DevOps, GitHub, through their command-line tools
- Reads freely, shows every write first
- Links, never copies

## Who it is for

- Developers: project hubs, repository blueprints, session logs
- Managers: team hubs, check-in logs, weekly reports
- Governance and tracking roles: initiatives, decision records, reports from queries

---

## Safety

- Asks before changing your words, never deletes or renames
- No secrets, no customer data, no HR matters
- Company-approved tools, work accounts, company backup

---

## Set up in 30 minutes

1. Install Obsidian, create an empty vault
2. Open an AI coding tool on it
3. Paste the build prompt
4. Set four Obsidian settings
5. Connect your tracker's command-line tool
