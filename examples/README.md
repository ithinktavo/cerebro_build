# Example: what the build prompt produces

This folder holds a vault built by the build prompt, so you can see the result before running it yourself. It was built for a placeholder persona, Alex Example, an engineering manager who kept the Teams, Code, and Blueprints blocks, dropped Terraform, named Azure DevOps as the tracker, and left every value that needs a real system as a marked blank.

- `sample-vault/` is the vault folder. Open it in Obsidian with "Open folder as vault" to browse it, or start with its `AGENTS.md`, the rulebook the prompt writes.
- Everything in it is placeholder text. No real team, repository, or tracker was read.
- The `AGENTS.md` and `CLAUDE.md` inside it belong to the sample and apply only in that folder.

Do not copy this folder as your own vault. Run the prompt on an empty vault instead, so that the build fits your role, your tools, and your tracker, and so that the dates and names are yours.
