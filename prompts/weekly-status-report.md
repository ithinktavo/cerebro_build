# Prompt: weekly status report

Paste this to the AI tool opened on your vault, with the brackets filled. Or save it in the vault as a dated `type: prompt` note in `Notes/` and refer to it by name: "run the weekly status report prompt for Alpha".

---

Write this week's status report for [team or project].

1. Read the tracker first. Run [the shared query or filter, by name or id] through [the command-line tool]. If none is set, query the open items in [project or area] plus the ones closed in the last 7 days. Group them: closed this week, in progress, no change in 14 days, blocked.
2. Then read the vault: the hub, the check-in log, and last week's report. Say if the tracker and the vault disagree, and which is newer.
3. Draft the report with these five headings and nothing else: Done, In progress, Blocked or at risk, Decisions needed, Next. One line per item. Every line ends with its source: the tracker item URL, the note link, or "said in chat" with the date. Write nothing you cannot source. Put open questions under Decisions needed.
4. Keep it under one page. Plain words, no adjectives, no "great progress".
5. Save it as a dated `type: report` note in the [team or project] folder, add it to the hub's list of notes, and show it to me in chat. Do not send it anywhere.
